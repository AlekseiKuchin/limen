# Изменения

## 0.2.0 — 30.10.2026

### Нулевое доверие
- План выборки хранит SHA-256 таблицы алертов и параметров аудита; `limen estimate` останавливается с кодом 3 при несовпадении.
- Результат хранит SHA-256 всех входов; новая команда `limen verify` сверяет хеши и заново выполняет расчёт.
- Новая команда `limen config-hash` — хеш параметров для протокола пилота до выгрузки данных.
- Журнал действий в JSON Lines (`--audit-log`, `LIMEN_AUDIT_LOG`) для SIEM заказчика.

### Разметка и мониторинг
- Офлайн-страница разметки (`limen plan --page-out`, `limen labeling-page`) вместо Streamlit: один HTML-файл, политика CSP по SHA-256, без сети, с замером времени, сохранением прогресса и выгрузкой CSV.
- Поле `attack_technique` (MITRE ATT&CK) в метках и раздел о техниках найденных атак в отчёте.
- Метрики Prometheus (`limen metrics`), правила Alertmanager и панель Grafana в `deploy/monitoring/`.

### Стек и сборка
- Командная строка на argparse вместо Typer; CSV вместо Parquet; SciPy выведен из ядра — специальные функции на стандартной библиотеке, сверены со SciPy в тестах.
- Сборка колёс зависимостей из исходников с проверкой хешей (`Dockerfile`, `toolchain/python-wheels/`), Trivy из исходников (`toolchain/trivy/`).
- CI: SonarQube, Trivy (SCA, секреты, конфигурации, SBOM, образ), DefectDojo, секреты из Vault по JWT, публикация в Harbor. Git-хук на Bash вместо фреймворка pre-commit; gitleaks и pip-audit заменены Trivy.
- Роль Ansible для установки на изолированный хост; `dvc.yaml` для исследования.

### Документация
- Карта процессов ГОСТ Р 56939-2024, документ по ИИ (приказ ФСТЭК № 117, закон № 243-ФЗ, ГОСТ Р по ИИ), законы, нулевое доверие, стек инструментов, ADR 0002 и 0003.
