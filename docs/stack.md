# Стек инструментов

Инструменты взяты из курсов автора — DevOps, DevSecOps и MLOps. Всё, чего в программах этих курсов нет, помечено «вариант» и может быть заменено без изменения архитектуры. Правило отбора: в ядро, которое ставится заказчику, попадает минимум зависимостей и ни одной сетевой.

## Ядро (ставится в контур заказчика)

| Компонент | Зачем | Откуда |
|---|---|---|
| Python 3.11+ | язык проекта | курсы MLOps, «Алгоритмы и структуры данных» |
| NumPy, pandas | таблицы алертов, выборка | вариант: базовые библиотеки анализа данных |
| pydantic | проверка конфигураций и маппингов | курс MLOps (раздел о качестве данных) |
| PyYAML | чтение YAML-конфигураций | вариант: де-факто стандарт для YAML в Python |
| Jinja2 | отчёты и офлайн-страница разметки | курс DevOps (шаблоны Ansible) |
| argparse, hashlib, statistics, math | командная строка, SHA-256, квантиль нормального распределения, специальные функции | стандартная библиотека Python |

SciPy из ядра убран: границы Клоппера–Пирсона, гипергеометрическая функция распределения и квантиль нормального распределения посчитаны на стандартной библиотеке и сверены со SciPy в тестах (`tests/test_special.py`). Так ядро не тянет Fortran и BLAS-зависимости SciPy при сборке из исходников.

## Чего в проекте нет и почему

- **Kubernetes, Helm, KServe, Airflow, Terraform** — из курсов, но продукту не нужны: «Лимен» — офлайн-утилита для одной машины, а не сервис.
- **Keycloak, LDAP** — у продукта нет многопользовательского сервиса: разметка идёт на офлайн-странице, расчёт — в командной строке.
- **OWASP ZAP, Burp Suite (DAST)** — нет веб-сервиса, который можно сканировать; офлайн-страница защищена политикой CSP и проверяется тестами.
- **Streamlit, Typer, pyarrow** — были в версии 0.1 и заменены: офлайн-страница вместо сервера Streamlit, argparse из стандартной библиотеки вместо Typer, CSV вместо Parquet.
