# Карточка модели-«автозакрывателя»

## Назначение

Модель нужна только исследовательскому контуру (`limen.research`): она изображает автоматизацию вендора, которую проверяет аудит. В поставку заказчику не входит, решений по реальным алертам не принимает. Ядро «Лимен» моделей не обучает: схема `active` берёт готовую оценку из поля `score` выгрузки.

## Данные

- Набор Microsoft GUIDE, обучающая часть; единица — инцидент; y = 1 для TruePositive, 0 для BenignPositive и FalsePositive ([research-protocol.md](research-protocol.md)).
- В каждом повторе модель учится только на организациях обучающей половины и применяется к организациям другой половины.

## Признаки

| Признак | Тип | Описание |
|---|---|---|
| `n_evidence` | число | улик в инциденте |
| `n_alerts` | число | разных алертов |
| `n_detectors` | число | разных детекторов |
| `n_categories` | число | разных категорий |
| `n_entity_types` | число | разных типов сущностей |
| `n_mitre` | число | улик с указанной техникой MITRE ATT&CK |
| `duration_h` | число | от первой до последней улики, часов |
| `hour` | число | час первой улики (UTC) |
| `top_detector` | категория | самый частый детектор |
| `top_category` | категория | самая частая категория |

Поля о действиях реагирования не используются: они появляются после решения аналитика.

## Обучение

CatBoostClassifier, функция потерь Logloss, только CPU. Параметры — в `configs/experiments/guide_audit.yaml`: 300 итераций, глубина 6, скорость обучения 0,1; если обучающих инцидентов больше 300 тыс., берётся случайная подвыборка этого размера. Зерно выводится из номера повтора. Файлы CatBoost на диск не пишутся.

## Как модель закрывает инциденты

На организациях аудита закрывается доля s инцидентов с наименьшей предсказанной вероятностью атаки (s = 0,30 и 0,68). Эта же вероятность служит оценкой f для схемы `active`.

## Ограничения

- Модель — заменитель автоматизации вендора; у реальных систем другие признаки, данные и пороги.
- Точность модели не влияет на корректность границ «Лимен» при равномерной и стратифицированной выборке; от неё зависит только ширина границы при схеме `active`.
- Перенос на российские SOC не проверен.
