# notebooks/

Блокноты для разведочного анализа GUIDE и синтетики и для графиков к отчётам по исследованию.

- Данные заказчиков в блокнотах не открываются: для них есть CLI и интерфейс разметки, которые работают по протоколу пилота.
- Код, нужный больше одного раза, переносится в `src/limen/` и покрывается тестами; блокнот только вызывает его.
- Перед коммитом выводы ячеек очищаются: в выводах могут оказаться фрагменты данных. Каталоги `.ipynb_checkpoints` и файлы `output*` исключены в `.gitignore`.
- Имя файла: `ГГГГ-ММ-ДД-тема.ipynb`, например `2026-11-02-guide-eda.ipynb`.
