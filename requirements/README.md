# requirements/

Экспорт `uv.lock` в формат pip с SHA-256 каждого пакета. Файлы создаёт `make lock` — его нужно выполнить один раз после клонирования и после каждого изменения зависимостей в `pyproject.toml`.

| Файл | Что внутри | Где используется |
|---|---|---|
| `runtime.txt` | зависимости ядра | сборка колёс из исходников в `Dockerfile` |
| `dev.txt` | ядро и инструменты разработки | задания CI: Ruff, mypy, PyTest |
| `research.txt` | ядро и исследовательский контур | прогон экспериментов на GUIDE |

Хеши проверяются при установке (`pip --require-hashes`): пакет, который отличается от зафиксированного, не установится. Править файлы вручную нельзя — только через `pyproject.toml` и `make lock`.
