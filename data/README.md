# data/

Содержимое каталога не коммитится: в Git попадают только этот файл и пустые `.gitkeep`. Git-хук `.githooks/pre-commit` (подключается `make hooks`) не даст закоммитить остальное.

| Каталог | Что лежит | Где допустимо |
|---|---|---|
| `raw/` | исходные выгрузки заказчика | только внутри контура заказчика |
| `interim/` | результат `limen prepare`: обезличенная таблица в канонической схеме | внутри контура; наружу — только минимальная таблица (`limen export-minimal`) |
| `processed/` | кэш инцидентов GUIDE (`*.csv.gz` и `*.meta.json`) | рабочее место исследователя |
| `external/` | открытые наборы данных (GUIDE) | рабочее место исследователя |
| `demo/` | синтетика и результаты `make demo` | где угодно: данные выдуманы |

## Данные заказчика

- Только с письменного разрешения заказчика и по [протоколу пилота](../docs/pilot-protocol.md).
- Сразу после получения — `limen prepare` с ключом заказчика; исходный файл в `raw/` удаляется, как только он больше не нужен.
- Каждую выгрузку сопровождает карточка ([docs/data-card-guide.md](../docs/data-card-guide.md)).

## Набор GUIDE

1. Скачать набор Microsoft Security Incident Prediction (GUIDE) с Kaggle — ссылка на страницу набора есть в статье [arXiv:2407.09017](https://arxiv.org/abs/2407.09017). Нужна учётная запись Kaggle.
2. Положить CSV обучающей части в `data/external/`. Конфигурации ожидают файл `data/external/GUIDE_Train.csv`; если имя другое, поправить `data.path` в `configs/experiments/*.yaml`.
3. Сверить названия колонок в `data.columns` с заголовком файла — они помечены «ПРОВЕРИТЬ».
4. Сохранить рядом текст лицензии CDLA-Permissive-2.0: при передаче данных её нужно прикладывать.
5. `python -m limen.research prepare --config configs/experiments/guide_audit.yaml` построит кэш инцидентов в `data/processed/`.
6. Чтобы зафиксировать версию файла, выполнить `dvc add data/external/GUIDE_Train.csv` (DVC, `dvc.yaml` в корне репозитория).
