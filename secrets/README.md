# secrets/

Здесь хранится ключ обезличивания, который создаёт `limen keygen` (по умолчанию `secrets/pseudo.key`). В Git попадает только этот файл.

- Ключ создаётся у заказчика и не покидает его контур: не пересылается, не кладётся в выгрузки, отчёты, тикеты и чаты.
- Права на файл — только владелец (600); `limen keygen` выставляет их сам. В Docker каталог монтируется только для чтения, поэтому ключ создаётся до запуска контейнера.
- Если у заказчика есть Vault, ключ удобно хранить там и выкладывать в этот каталог агентом Vault на время аудита.
- На каждый аудит — новый ключ: тогда псевдонимы разных аудитов нельзя связать между собой.
- В основном режиме ключ нужен до конца аудита: без него нельзя перевести шаблон и метки между псевдонимами и исходными `alert_id` (`limen translate-ids`). Потерянный ключ не восстановить — придётся создать новый, заново выполнить `prepare` и `export-minimal` и пересобрать план с тем же зерном.
- Путь к ключу можно задать переменной `LIMEN_PSEUDO_KEY_FILE` вместо параметра `--key`.
